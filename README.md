# roviracadena.github.io

Portafolio de Sebastián Rovira (ROCAZ) — desarrollo web, SEO y GEO.

- Sitio estático: HTML + CSS + JS, sin build. GitHub Pages sirve la rama `main`.
- SEO/GEO: JSON-LD (Person, WebSite, FAQPage), `sitemap.xml`, `robots.txt` con crawlers de IA permitidos, `llms.txt`.
- Capturas de proyectos en `img/`. Imagen para redes: `img/og.png` (1200×630).

Para actualizar: editar `index.html`, hacer commit a `main` y esperar ~1 min.
